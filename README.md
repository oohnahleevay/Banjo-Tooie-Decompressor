# Banjo-Tooie Decompressor

## INSTALLATION

> pip install -r /path/to/requirements.txt

## USAGE

1) Place a copy of the Banjo-Tooie ROM in the root folder.

2) Run the main file. This will extract and decrypt all assets.
> python3 main.py
